# **混合特效管线架构说明书**

**1. 架构总览**

本系统采用“双轨制并线”架构，将游戏内的特效严格划分为两类进行独立管理。其核心目的在于彻底解耦逻辑层与表现层，消除高频特效对网络带宽与系统内存的压力，同时优化美术的工作流。

- **即发即弃型：** 适用于无固定位置、播完即毁的散装特效（如受击飙血、子弹火花）。此类特效由纯本地的全局对象池 `GlobalLocalVFXPool` 统一调度。
  - *特别说明：为了保证管线职责的绝对纯粹，`GlobalLocalVFXPool` 是完全独立于网络对象池 (`SyncObjectPool`) 与普通本地池 (`LocalObjectPool`) 的第三套独立系统。它仅处理视觉层表现，此类特效预制件绝对禁止挂载 `NetworkObject` 等网络组件。*
- **状态附着型：** 适用于跟随模型骨骼移动、需要精确控制播放与停止状态的专属特效（如眼部红光、武器拖尾）。此类特效采用“预拼装”模式，直接挂载于实体的骨骼下，由 `MonsterVFXController` 进行统筹控制。

**2. 核心组件与变量说明**

**2.1 实体附着特效系统**

负责处理与特定怪物模型强绑定的特效。

- **`MonsterVFXController` (实体特效控制器)：**
  - 定位：挂载于怪物预制件根节点，负责扫描预先拼装好的特效，并接收网络触发事件。
  - `prebakedEffects` (List<PrebakedVFX>)：预拼装特效绑定列表。
    - `eventId` (string)：特效的唯一触发口令（如 "EyeGlow"）。
    - `vfxObject` (GameObject)：已经提前摆放在怪物骨骼下的特效游戏物体。
- **`CachedVFXWrapper` (底层包装器)：**
  - 定位：内部功能类。自动深度扫描并控制目标物体及其子物体上的 `ParticleSystem`、`VisualEffect` 与 `Animator`。美术可自由选择并嵌套特效组件，无需更改程序逻辑。

**2.2 全局本地特效池系统**

负责处理全场通用的高频环境与打击特效。

- **`GlobalLocalVFXPool` (全局特效池)：**
  - 定位：场景单例，独立于逻辑网络。
  - `registries` (List<VFXRegistry>)：通用特效注册表。包含 `id`（全局唯一标识）、`prefab`（特效预制件，必须勾选 Play On Awake）、`defaultCapacity`（初始对象池大小）。
- **`VFXAutoReturn` (自动回收器)：**
  - 定位：必须挂载于即发即弃的特效预制件根节点。
  - `vfxId` (string)：对应全局池中的注册标识。
  - `lifetime` (float)：特效存活时间。倒计时结束后自动归还至全局对象池。

**3. 运行逻辑**

1. **场景初始化：** 游戏启动时，`GlobalLocalVFXPool` 读取通用特效注册表，预先生成对应数量的特效对象并休眠，完成全局池构建。
2. **实体初始化：** 怪物生成时，其身上的 `MonsterVFXController` 扫描 `prebakedEffects` 列表中的物体，将它们封装进 `CachedVFXWrapper` 并存入缓存字典，同时调用 `Stop()` 确保初始状态隐藏。全程无文件读取与实时实例化的性能消耗。
3. **网络触发：** 战斗逻辑（仅限服务器端）需要播放特效时，向网络发送仅包含字符串的 RPC 广播。
4. **本地渲染：** 所有客户端收到字符串指令后：
   - 如果是通用特效标识（如 "HitBlood"），直接向 `GlobalLocalVFXPool` 申请指定位置的特效播放。
   - 如果是专属特效标识（如 "EyeGlow"），控制器直接在缓存字典中唤醒对应包装器的 `Play()` 方法进行播放。
5. **生命周期完结：** 通用特效播放完毕后，由 `VFXAutoReturn` 自动回收至全局池；专属特效则无需回收，其生命周期跟随怪物实体，怪物回池销毁时一并处理。

**4. 调用说明与具体示例**

规范要求：逻辑层代码中绝对禁止使用 `Instantiate` 生成特效，必须通过以下标准管线进行触发。

**示例 A：配置与触发怪物的专属特效（如：近战扑击前的红眼预警）**

- **配置步骤（所见即所得）：**

  1. 双击打开需要添加特效的怪物预制件。
  2. 将红眼特效的预制件，直接拖拽成为怪物头部骨骼（如 Head_Bone）的子物体。
  3. 在场景中直观地调整该特效的坐标、旋转与缩放，直到视觉效果完美。
  4. 选中怪物根节点的 `MonsterVFXController` 组件。
  5. 在 `prebakedEffects` 列表中新增一项：`eventId` 填入 "EyeGlow"，`vfxObject` 拖入刚才挂载好的红眼特效物体。

- **调用步骤：** 在怪物的 AI 攻击逻辑中（确保在服务器端运行）：

  ```c#
  // 触发本实体的专属特效
  GetComponent<MonsterVFXController>().BroadcastVFX("EyeGlow");
  ```

**示例 B：配置与触发通用受击特效（如：子弹打中怪物的飙血效果）**

- **配置步骤：**

  1. 制作飙血特效预制件，确保粒子系统组件勾选 `Play On Awake`。
  2. 为该预制件根节点挂载 `VFXAutoReturn` 脚本。将 `vfxId` 设为 "BloodSplash"，`lifetime` 设为 1.0。
  3. 找到场景中的 `GlobalLocalVFXPool` 单例节点，在其注册表中新增一项，填写 ID 为 "BloodSplash" 并拖入该预制件。

- **程序调用步骤：** 在服务器的伤害结算逻辑中，发送一个 ClientRpc 通知所有客户端：

  ```c#
  [ClientRpc]
  private void SpawnHitVFXClientRpc(Vector3 hitPos, Quaternion hitNormal)
  {
      // 客户端收到坐标后，通过全局本地池播放
      GlobalLocalVFXPool.Instance.PlayVFX("BloodSplash", hitPos, hitNormal);
  }
  ```
