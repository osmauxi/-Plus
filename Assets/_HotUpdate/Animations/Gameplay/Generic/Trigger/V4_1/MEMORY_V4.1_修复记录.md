# V4.1 修复记忆

## 永久禁止再次采用的方案

不要把首尾姿态或速度差通过 Hermite、线性偏移或其他函数分摊到整个动画。即使最终首尾数值完全相同，这种方法仍会重写动作中段。也不要用经过相同闭环修改的参考动画做保真验收。

## 正确验收基准

- 参考必须来自未经闭环改写的原始 FBX。
- 裁切动画时，参考使用相同的原始帧范围并平移到输出 0 帧。
- 关键帧精简后逐帧比较全部 99 个骨骼的世界姿态。
- 明确允许修改的接缝帧单独报告；其余帧必须满足旋转 ≤0.5°、位置 ≤0.2 cm。
- 不能只依据 Unity 导入后的关键帧数量或 `Keyframe Reduction` 判断源 FBX 是否修复。

## V4.1 循环策略

- Aim Idle：源 0–240，源首尾已近似闭合，不修改接缝。
- Aim Walk Forward：源 0–46，源首尾已近似闭合，不修改接缝。
- Jog：源 0–46，源首尾已近似闭合，不修改接缝；禁止 27→14 拼接。
- Aim Walk Backward：源 18–36，只修改输出最后 2 帧。
- Aim Walk Left：源 17–36，只修改输出最后 2 帧。
- Aim Walk Right：源 22–45，只修改输出最后 2 帧。
- 接缝修改使用最近等价旋转，只能发生在获准的末尾帧，不得扩散到动作中段。

## Sprint 接入契约

- 导出包只提供完整 `Game_Sprint_StartForward.fbx`，源/输出均为 0–77 帧。
- 不在 FBX 导出包中交付 `Game_Sprint_Loop.fbx`。
- Unity 接入阶段可先检查 StartForward 36–66 帧作为稳定疾跑候选范围，再按脚步相位派生该角色专属 `.anim`。
- 不得把完整 StartForward 直接设为循环。

## 其他不变契约

- 不修改原模型、蒙皮、99 节点骨架层级、名称或参考姿势。
- Generic Rig；单动画单 FBX；30 FPS。
- 动画文件无 Mesh/Skin/材质。
- `Bip001` Position/Rotation 恒定，Scale 恒定为 7。
- Unity Scale Factor 1，Apply Root Motion 关闭。
- 常量曲线单键，动态曲线在误差限制内精简。
