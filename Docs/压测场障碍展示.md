# 压测场障碍展示

房间资源：`Assets/_HotUpdate/Prefabs/Rooms/Room_Grid_Start.prefab`。
当前 StressArena 复用该房间，因此本次修改也会出现在普通地图的起始房间。

## 布局与配置

- `NavigationDemo/FixedWalls`：四段蓝色固定墙，错位排列，中央留出玩家出生和活动区域。
- `NavigationDemo/PatrolWalls`：两段橙色巡回墙，分别沿房间 X、Z 轴往返。
- 每面巡回墙的 `RoomPatrolWall` Inspector 可调整父节点局部坐标端点、单程秒数、端点停留和相位偏移。选中墙体可看到巡回路径 Gizmo。
- 移动范围随房间 Scale 放大，巡回周期保持不变。当前单程分别为 16、14 秒，端点停留 2 秒。

固定墙的导航代理位于 `MinimapBakeRoot/NavigationDemo_FixedWalls`，已重新烘焙空间数据和小地图。手工修改固定墙位置或尺寸时，同时调整对应 Bake 方块，再执行 `Tools/Map/Minimap/Bake Selected Room` 并保存 prefab。巡回墙不要加入静态 BakeRoot，否则会留下不能解除的静态阻挡。

## 运行方式

巡回墙使用 NGO ServerTime 计算当前往返位置，在 Gameplay `TickAdvanced` 更新 Transform，随后房间怪物 Tick 更新阻挡格与 Flow Field。各端按服务器时间展示同一条轨迹，无须为墙体增加 NetworkObject。

动态导航直接变换 BoxCollider 的本地包围盒，不依赖 Physics 同步时机；多个墙体重叠时按格子计数，只有最后一个障碍移走才解除阻挡。

## 已验证

- Unity 脚本编译通过。
- Scale 6、旋转 90 度下，72 秒内的 145 个巡回位置均保持全部可走格与中央连通。
- 两面墙重叠、分别离开后，阻挡保留与解除正确。
- 512 只怪物模拟 900 Tick（30 秒）：固定墙侵入次数为 0，475 只进入中央 60 世界单位范围，平均距中央由 150 降至 13.02。

上述为 Editor 内直接驱动正式导航与怪物模拟的逻辑烟测，不是 5012 只怪物的联网 Player 性能基线。后续 Player 测试需要重新构建热更 DLL 和房间所属 Addressables 内容。
